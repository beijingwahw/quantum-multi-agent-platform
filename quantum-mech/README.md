# quantum-mech — 量子机制设计原型（未来技术版图 #4）

**把 DSIC 定理推广到量子信息不对称世界：不可克隆保障的报价隐私、纠缠态作为合约。**

回答三个问题：量子化通信通道会**改变**激励相容吗（T1：不会——守恒定律）；
量子到底**买来**什么（隐私：锁定、可检测扰动、最小 transcript；抵押：单配性排他）；
哪里**注定不行**（承诺绑定 no-go、近似求解器进 VCG 的激励危险）。
TypeScript 严格模式、零运行时依赖、NodeNext、node:test；`npm run repro`
一条命令全量重建本 README 引用的所有数字。

## 核心结果（全部可由 `npm run repro` 重建）

1. **T1 · DSIC 守恒定理**（`out/exp1-dsic.md`）：期望效用对提交的密度矩阵
   是仿射的（机器验证残差 ~1e-16），正交码字实现全部点报告 ⟹ 量子偏差
   最优值 = 经典混合策略最优值。第二价格拍卖在任意量子偏差（码字 +
   500 随机纯态 + 混合）下增益恒等于 0；第一价格的经典压价原样存活
   （增益 1.0）。相干比较器路径（联合幺正 + 部分测量）同结论。
2. **隐私 · 不可克隆密封竞价**（`out/exp2-privacy.md`）：
   - Wiesner 锁定 2 基（BB84 型）**泄露** χ≈0.399/比特、3 基 χ≈0.256/比特
     ——共轭基本身不等于隐藏；加经典 pad（量子一次一密）χ=0 精确成立；
   - 窃听-重发扰动率 (1−1/nBases)/2/比特、检测率 1−(2/3)^Q（3 基），
     蒙特卡洛与解析吻合；
   - 相干比较器只读出 (winner, price)：全部输家身份与第三名以后的报价值
     永不进 transcript——隐藏剖面对的绝对数量随规模增长（3×3 场 40 对、
     4×3 场 411 对），比例保持 O(1/k)（经典拍卖员 100% 可区分）。
3. **纠缠合约 · 单配性排他**（`out/exp3-escrow.md`）：CKW 锚点机器命中
   （GHZ tangle=1、W pairwise=2/3）；同一抵押量子比特向两家托管 pledging
   的最优 min concurrence 恰为 **1/√2**（构造族 √x|100⟩+… 在 x=½ 精确触顶）
   vs 独占 Bell pledge 的 1——**合同的排他性由物理保证**；Bell 保真度
   F₁+F₂ ≤ 1 全族成立，验收阈值 >½ 即最多通过一家。Wiesner 抵押代币
   伪造率 (3/4)^m 与模拟吻合（m=12 时 3.2%→3.2%）。
4. **诚实墙 · 承诺 no-go 可执行化**（`out/exp4-nogo.md`）：HJW steering
   表——同一个 |Φ⁺⟩、同一个 I/2，承诺方事后选基（Z/X/Y）决定验证方
   坍缩进哪个系综分解（各成员概率 ½、保真度 1）；朴素协议实测：EPR
   骗子完美隐藏（T(I/2, I/2)=1e-16）但每个 reveal 通过率恰 ½，经典等角
   作弊 0.8536。**量子买隐私与检测，绝不买绑定——绑定只能来自经典托管
   签名。**
5. **T5 · 近似求解器进 VCG 破坏 DSIC**（`out/exp5-vcg.md`）：40 个随机
   3×3 指派实例 × 穷举误报搜索：精确分配器 **0/40 违反**；最优解 + 1 次
   随机换位的扰动分配器 **18/40 违反**（最大增益 5.0），3 次换位 28/40。
   Groves 支付公式配近似分配 = 激励不相容——"几乎最优"在机制设计里
   是范畴错误。这正是主平台"可证明最优求解器"定位的激励侧论据。

## 定位与先行工作（如实划界）

量子拍卖协议不是新东西：Naseri 2009 起的 GHZ 密封竞价系、Hogg-Harsha-Chen
2007 的超position竞价与输家隐私、H. Wu 2010/2011 的量子策略进机制设计、
Rubinstein et al. 2023 的拍卖量子通信复杂度。本原型的增量是**可执行的
定理层**：DSIC 在量子信道下的一般守恒（机器验证到 1e-15）、单配性作为
合约排他性的定量刻画（1/√2 天花板）、no-go 的 steering 引擎演示、以及
近似求解器的激励危险反例库。详见 `docs/theory.md` 与 `docs/citations.md`。

## 诚实的边界

- 2 基/3 基裸 Wiesner 锁**有残余信息**（χ>0，如实测出）；精确隐藏需要
  量子 OTP（2 key bits/qubit）。小钥匙锁定的渐近优势（数据锁文献）未实现。
- transcript 最小化对 **honest-but-curious** 拍卖员成立；恶意拍卖员可拒
  不擦除 junk 寄存器——擦除是可审计的运维假设，不是定理。
- 纠缠抵押的验证是**私钥**模型（托管知道代币秘密）；公钥量子货币仍是
  开放问题。保真度数字假设理想信道。
- 承诺绑定由 no-go 定理**原则上不可能**（引用 Mayers / Lo-Chau；本仓库
  演示其 steering 引擎，不重证定理）。
- 近似求解器危险是经典已知现象（Nisan-Ronen 2001 / Nisan 2007）在量子
  求解器语境下的具体化，不是新定理。
