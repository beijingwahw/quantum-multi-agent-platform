# Theory — statements, proofs, and honest boundaries

Everything on this page that has a number is regenerated by `npm run repro`;
tests pin the same values. Statements that are NOT proved here (compositional
security, LWE-based classical verification, the BH symmetric cloner) are
listed as cited boundaries at the end.

## T1 — Blindness as an exact identity

Prepare-and-send UBQC (Broadbent–Fitzsimons–Kashefi 2009): the client sends
|+_{θ_v + φ_v}⟩ per qubit, θ_v the MBQC angle (secret), φ_v a one-time pad.

**Identity (machine-checked).** For every secret θ,
  E_φ[⊗_v |+_{θ_v+φ_v}⟩⟨·|] = I/2ⁿ  exactly,
because each single-qubit average over the four pads {0, π/2, π, 3π/2} is the
maximally mixed state. Verified by exhaustive pad enumeration at n = 1..4:
worst trace distance to I/2ⁿ is 2.4e-16, and the worst gap between two
different secrets' server views is at fp noise.

**Angle one-time-pad, two regimes (exact integer arithmetic over Z_8).**
- Standard pads {0, 2, 4, 6} (as eighth-turns): δ = θ + φ leaks **exactly
  1 bit** — the quadrant coset of θ. This is by design: the quadrant is
  absorbed by the flow corrections. H(θ|δ) = 2 bits.
- Full-group pads {0..7}: I(θ;δ) = 0, H(θ|δ) = 3 bits. A perfect OTP on the
  angle group.

**Negative control.** Without pads, the 8ⁿ-ensemble of server states has
Holevo χ = n bits and pairwise trace distance 1 (at n = 2, 3: measured 2.0 and
3.0 bits, distance 1.0) — the pad structure is exactly what zeros leakage.

## T2 — The trap detection calculus

FK-trap kernel: trap qubit |+_θ⟩, θ uniform over the 8 equatorial angles; the
verifier later reveals basis θ (the state is its +1 eigenstate: honest
acceptance 1). A deviating server applies Λ = {E_j} before the reveal.

**Formula (three-way machine-checked).** Writing E_j = c_{j,I}I + c_{j,X}X +
c_{j,Y}Y + c_{j,Z}Z and using ⟨+θ|X|+θ⟩ = cos θ, ⟨+θ|Y|+θ⟩ = sin θ,
⟨+θ|Z|+θ⟩ = 0:

  p̄(Λ) = Σ_j |c_{j,I}|² + ½ Σ_j (|c_{j,X}|² + |c_{j,Y}|²)

(averaging over the 8 secret angles kills cos θ, sin θ, cos θ sin θ and
averages cos²θ, sin²θ to ½). The density-matrix referee and the per-angle
Pauli-expansion referee agree to 4.4e-16 on 60 random CPTP maps.

**Tier structure.** Z Kraus components are detected with certainty (they
contribute 0); X and Y components with probability exactly ½; the identity is
invisible. Hence the exact bound

  p̄_reject ≥ ½ (1 − idMass),  idMass = Σ_j |c_{j,I}|²,

tight for the family {√(1−q) I, √q X} with acceptance exactly 1 − q/2. t
independent traps multiply: acceptance p̄^t (t = 20 → < 1e-6 for the worst
non-identity attack).

**Blind spot (honest).** A deviation that never touches the trap (arbitrary
unitary on a garbage register) leaves acceptance exactly 1 — measured, not
assumed. Traps constrain only what they touch; full protocols interleave
traps with the computation and add output checks (cited: FK, Dunjko–Kashefi–
Leverrier composable security).

## T3 — CHSH rigidity as the verification kernel

**Horodecki formula.** For a two-qubit ρ with T_{ij} = Tr(ρ σ_i⊗σ_j),
S_max(ρ) = 2√(u₁+u₂) with u₁ ≥ u₂ the top eigenvalues of TᵀT. Referee:
deterministic multistart compass search over the four Bloch directions
agrees to ≤ 5.2e-13 on Bell states, the Werner curve (analytic 2√2·F, worst
deviation 8.9e-16), the Schmidt sweep, and 30 random mixed states.

**Tsirelson bound (analytic; sampling is a check).** S = ⟨A₀⊗(B₀+B₁) +
A₁⊗(B₀−B₁)⟩ with ±1-valued observables; squaring and using ⟨O⟩ ≤ ‖O‖ for
states: S² ≤ ⟨(A₀⊗C + A₁⊗D)²⟩ with C = B₀+B₁, D = B₀−B₁; C² = 2I + {B₀,B₁} ⪯
4I, D² ⪯ 4I, and the cross anticommutator term is dropped conservatively
(signed appropriately), giving S² ≤ 8, i.e. S ≤ 2√2. No sampled state
exceeds it.

**Pure-state rigidity law.** S_max = 2√(1 + C²), C the concurrence — exact
quantitative self-testing: a violation certifies entanglement and pins the
Schmidt angle. Machine agreement ≤ 6.1e-9 over the sweep (the optimizer's
resolution; the formula-vs-closed-form agreement is 1e-15).

**Game form.** W = ½ + S/8: quantum optimum (2+√2)/4 = 0.853553, classical
optimum exactly ¾ (16-strategy enumeration). MC (40000 rounds) 0.8525 ± 0.0018.

**Honest boundary.** Isotropic/Werner states with F ∈ (1/3, 1/√2] are
PPT-entangled but CHSH-local (measured: F = 0.65 has PPT min-eigenvalue
−0.237 < 0 and S_max = 1.838 < 2). CHSH verification is sufficient, not
necessary — noisy honest devices can fail rigidity while being genuinely
quantum.

## T4 — Sampling-based certification

**Shadows (Huang–Kueng–Preskill).** Local random-Pauli snapshots ρ̂ = R†(⊗_v
(3|b_v⟩⟨b_v| − I))R satisfy E[ρ̂] = ρ exactly — verified by full enumeration
(3ⁿ bases × 2ⁿ outcomes, exact probabilities), worst trace distance ≤ 1e-15
at n = 2, 3, pure and depolarized, including complex phases. Linear fidelity:
E[⟨ψ|ρ̂|ψ⟩] = ⟨ψ|ρ|ψ⟩; MC matches (1−q) + q/2ⁿ within statistical bars.
(Note the rotation-direction subtlety: the measurement rotation is R = U†
where U's columns are the basis eigenstates; H is self-adjoint so only
complex bases expose the direction — a regression test guards this.)

**Mirror echo.** Per-layer global depolarizing D_λ (forget to I/2ⁿ w.p. λ)
gives the exact closed form F_return = (1−λ)^L + (1−(1−λ)^L)/2ⁿ: once any
forget happens, later unitaries leave the maximally mixed state (return
probability exactly 2^{-n}); never-forgetting returns 1. Simulation matches
to 1e-16. Local per-gate depolarizing is simulated exactly and reported as a
curve — no closed form is claimed for it.

**XEB.** Exact facts by enumeration at n = 8 (depth 3n): uniform sampler
gives F_XEB = 0 (to fp); ideal gives 2ⁿΣp² − 1 = 1.141 (Porter–Thomas-like);
depolarizing λ scales it exactly: F_XEB = λ(2ⁿΣp² − 1) (MC within 2σ).
**Spoof:** the product-of-marginals distribution q = p_A·p_B (classical cost
~2^{n/2} via contraction) scores F_XEB = 0.436 while sitting at total
variation distance 0.294 from the ideal — positive XEB does not certify the
computation. **Sample wall:** exact-ideal evaluation cost doubles per qubit
(5.0 ms → 955.8 ms from n = 8 to 16); XEB verification includes the
verifier's classical simulation bill. Device-independent certification
lower bounds: Hangleiter–Kliesch–Gogolin–Eisert PRL 122, 210502 (2019).

## T5 — Optimal attack games

**(a) Helstrom pair.** Distinguishing |+_θ⟩ from |+_{θ+π/4}⟩ (the one-bit
uncertainty a server faces about a trap secret): p* = (1+sin π/8)/2 =
0.691341716183 — trace-norm formula, closed form, and direct binary-POVM
optimization (all 2×2 effects are E = (I+r·σ)/2, |r| ≤ 1) agree to 1e-12/1e-6.

**(b) BB84, two games.** Label discrimination ("which of the four states"):
PGM attains ½ and the dual feasible point Γ = I/4 ⪰ ¼ρ_k certifies ½ optimal.
Bit discrimination ("which bit, basis unknown"): Helstrom between the
bit-ensembles gives exactly ½ + √2/4 = (2+√2)/4 = 0.853553 — the same
constant as the quantum CHSH game value; both are the 22.5° geometry of √2.

**(d) Commit-then-reveal wall.** If the server must return a qubit (and claim
an outcome bit) before the basis θ is revealed, acceptance is exactly ½ for
every strategy: (1/8)Σ_θ Π_θ⁺ = I/2 (machine-checked matrix identity), so the
averaged acceptance is Tr(ρ_ret)/2. MC over random attacking channels
confirms 0.5000 ± 0.0035.

**(c) Optimal keep-a-copy attack.** The universal individual-copy optimum is
the shrink-(2/3) channel {√(3/4)I, √(1/12)X, √(1/12)Y, √(1/12)Z} (5/6
universal fidelity, BH bound). Machine-verified: trap acceptance is exactly
5/6 at every secret angle (constant price: 1/6 detection risk per trap); the
Stinespring complement V₀|ψ⟩ = √(3/4)|ψ⟩|0⟩ + √(1/12)Σ_σ σ|ψ⟩|σ⟩ is an exact
isometry (1e-16); the deferred Helstrom guess on the kept environment is
exactly (1 + ⅔ sin π/8)/2 = 0.627561144122 — versus 0.691342 for holding the
untouched original. Exact exchange rate: 1/6 detection risk buys a 0.1276
guessing edge over blind.
