# 第 7 章 已知边界与后续

本章是审计的诚实性声明：哪些结论可信、哪些区域没看到、静态审读的固有局限、以及建议的下一步。任何审计报告的价值取决于其边界是否被显式声明——本章即为此而写。

## 7.1 审计方式与置信度分级

本次审计采用 9 路并行深审（7 路外派 Agent + 2 路主线亲审）+ 交叉复核抽查回读。约 190 条去重后发现的置信度分三档：

| 档位 | 定义 | 覆盖内容 |
|---|---|---|
| 高置信 | 回读验证源码 / 主线亲审 / 官方来源 | P0 plugin 串行（plugin.ts:140-186）、P1 状态守卫缺失（quantum-scheduler.ts:~460）、P1 overloaded 吸收态（quantum-scheduler.ts:402-406）、全部 QPU/基建发现（主线亲审）、Node 20 EOL（2026-04-30）与 ESLint 9 EOL（2026-08-06，官方来源） |
| 中置信 | 单源 + 行号自洽 | core 优化器各 P1（子空间回退 chosen=0、worker 序列化脆弱性、主线程阻塞）、总线 cardinality 攻击面 |
| 待深化 | 覆盖缺口或表述分歧，建议后续验证 | 见 7.2 与 7.3 |

两点方法论说明：① 各 subagent 行号自注 ±10 行误差（复核实测 plugin 串行实际在 140-186 行而非声称的 200-233，偏差在容差内）；② 严重度排序按「影响面 × 修复成本」重排过——例如 plugin 串行动作定 P0（事件风暴下堆积无界），而 executor 重试不分类定为 P1，是重排后的结论而非审计员原始判断的照单全收。

## 7.3 保留分歧与待验证疑点

复核中存在一处表述自相矛盾，按「疑似」降级处理而非采信为结论：

- **bruteForceOptimum 耦合键一致性（subagent_08 #13）**：审计员先称 dfs 与 computeEnergies 的耦合编码一致、后又指出 q1==q2（对角项）在三条求解路径上语义不一致——同一发现内部表述冲突。本报告将其降级为「**疑点，建议验证**」，列入 Wave 3 快照测试的验证清单（构造含对角耦合的实例，对照 bruteForce 与态矢量路径的能量语义），在验证完成前不作为 P1 结论引用。

## 7.4 审计环境限制

- **静态审读为主，未运行测试套件**：全部发现来自读码推断，28 文件 5822 LOC 的测试套件（README 称 281 用例）未在本次审计中实际执行——CI 全绿状态以仓库自述与配置为准，未经独立复现。
- **行号为近似值**：各 subagent 行号自注 ±10 误差，按函数名回查均可定位；引用时建议以函数名为主锚点。
- **未验证运行时行为**：主线程阻塞时长、worker 握手超时、事件风暴堆积等性能类发现（如 subspace-parallel 的分钟级阻塞声称）为代码路径推断，量级判断基于参数推导而非实测。
- **前沿基准的固有缺口**（subagent_04 诚实标注）：fast-check 采纳率、AI review 误报率（5-15% 来自非权威来源）、c8 最新版本号、变更行覆盖普及率——均无权威统计，本报告未将其作为硬基准引用。

## 7.5 后续建议

1. **先修再测**：按 Wave 1 清单（第 5 章）执行三条已验证 P0/P1 的最小补丁 + EOL 清理 + CI 硬化——1-2 天工作量，全部为高置信发现，无验证依赖。
2. **回归 CI 全绿后再进 Wave 2**：状态机集中化是回归风险最高的改造，安全网 = Wave 1 新增回归测试 + 现有覆盖率门禁；若 CI 存在未知间歇红（本次未运行套件，无法排除），先按 Wave 3 条目 3.3 消灭 setImmediate 魔法数再动状态机。
3. **优先补两个安全相关缺口**：tools/ 三文件与 dsh-integration.ts 的深审建议提前（它们是外部输入的直接处理面），web-console 补一次运行时验证（鉴权失败断连路径、XSS 实测）。
4. **对「疑点」项做一次验证实验**：bruteForceOptimum 对角耦合语义——验证成本小时级，结论直接影响「精确最优参照是否可信」这一算法正确性根基。

## 7.6 结语

本次审计的最终判断可以收敛为一句话：**内核是世界级的，外围欠账是可还的，路线图是可执行的**。约 190 条发现中真正的系统性风险集中在状态机完整性、异步并发纪律、EOL 工具链、测试时序确定性四处——全部有明确修复路径（第 5 章）且不触及内核设计。与此同时，第 6 章列出的 19 项资产——从定理级机制注释到位级一致性的确定性工程——值得原样保留并继续投资。按波次推进，这个仓库有充分条件在 2027 年站上同类项目的第一梯队。
