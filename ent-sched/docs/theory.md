# ent-sched 理论文档

推导与命题的机器验证记录。所有公式先在此推导，再由 `src/physics/referee.ts`
的独立密度矩阵电路否决或确认（`test/physics.test.ts` 锁定到机器精度）。

## 1. Bell 标签代数

标签 i = z·2 + x（相对 |Φ⁺⟩ 的 Pauli 帧）：0=Φ⁺, 1=Φ⁻（Z）, 2=Ψ⁺（X）,
3=Ψ⁻（ZX）。态 = Bell 向量 λ∈Δ³。Werner 态：werner(F) = (F, w, w, w)，
w=(1−F)/3。

**交换（BSM + 完美帧修正）= XOR 卷积**（裁判：CNOT(1→2)+H(1) 分析器，Φ⁺
分支；Φ⁻ 分支 + Z 帧修正逐点等价——帧修正等价性本身是测试项）：

  λ′_k = Σ_{i⊕j=k} λ_i μ_j

Werner 类封闭：**F′ = F₁F₂ + (1−F₁)(1−F₂)/3**。k 跳新鲜链的闭式与向量
复合在 exp1 互证到 1e-14。

**存储退极化（替换信道）**：λ → (1−p)λ + p·u；p(t) = 1−e^{−t/T₂} 每量子
比特独立。引擎为每个对保存两端量子比特的物理创建轮 tA/tB 与向量精确时刻
sA/sB，老化只对差值 (now−tX)−sX 计一次——跨交换/纯化绝不重复计 aging。

## 2. BBPSSW 纯化与 twirl（本项目最大的物理教训）

协议：双边 twirl → 双边 CNOT → Z 校验后选择 → twirl。对 twirled 输入
（Werner, f₁, f₂, wᵢ=(1−fᵢ)/3）：

  P = (f₁+w₁)(f₂+w₂) + 4w₁w₂,   F′ = (f₁f₂ + w₁w₂)/P

**twirl 的作用**：双边旋转群在 Bell 标签上的作用固定 Φ⁺（因为对任意 R，
(R⊗R)|Φ⁺⟩ = (RRᵀ⊗I)|Φ⁺⟩，实旋转 RRᵀ=I；复旋转的位移由经典记录的 Pauli
帧修正收回），三个误差标签被均化——twirl(λ) = werner(λ₀)。

**为什么每轮必须 twirl**（实测教训，test 有回归守卫）：一轮纯化后的输出
不是 Werner——误差集中在 Z 扇区（λ₁ = 2Fw/P ≫ w′）。不 twirl 直接与新鲜
Werner 对继续纯化，Z 扇区卷积把 Φ⁺ 权重稀释：**F 0.884 → 0.850 的实测回
退**。twirl 后 (0.884, 0.85) → 0.898，递归恢复单调。

**阈值命题（机器验证）**：BBPSSW 改进 F ⟺ F > 1/2——恰是纠缠阈值；不动
点 F=1/2 精确到 1e-14；从任何 F>1/2 迭代收敛到 1。

裁判实现要点：twirl = Bell 基下固定 Φ⁺ 的六置换均匀平均（双边旋转+帧修正
的实现抽象）。我们最初尝试直接枚举双边旋转群的闭包，遇到两个可复现的坑：
(i) ⟨H⊗H, Ry(π/2)⊗Ry(π/2)⟩ 固定 Ψ⁻（轨道只有 {Φ⁻,Ψ⁺}，不传递，twirl 无
效）；(ii) 加入 K=S·H 后与 Ry 的闭包数值上稠密（超 96 元素上限）——最终
改为置换平均。教训：**双边旋转固定 |Ψ⁻⟩（实矩阵）或移动 |Φ⁺⟩（复矩阵），
"固定 Φ⁺ 且传递误差标签"是帧修正后的合成作用，不是任何单个旋转群的作用。**

## 3. 密钥分数与资源度量

单向密钥分数 r(λ) = 1 − H(λ)。Werner 阈值 **F\* = 0.810849…**（二分法解
r(F)=0，与 QKD 文献口径一致）。Bell 对角 concurrence C = 2max(0, F−1/2)。
交付记账：good（F ≥ fMin）/bad 分开计数，密钥率只累计 good 的 r。

## 4. 引擎与 Markov 裁判

轮次顺序（引擎与 DTCS 严格一致，互证前提）：

1. 截止：age = now − tX > cutOff 的对丢弃
2. 策略分配尝试槽（生成带宽）
3. heralded 尝试（每槽 Bernoulli(p)，新对 age=0）
4. 策略决策交换/纯化/丢弃（看到含新对的状态）
5. 执行（交换失败双毁；纯化按公式概率）
6. 交付：完整对 F ≥ fMin 自动交付；低于 fMin 询问策略 deliver/hold

**2 链路精确 DTMC**（M=1、饱和、asap）：状态 (a₁,a₂)∈{0..K+1}²（年龄；
无噪声/无截止退化为 4 态 {空,满}²）。平稳分布高斯消元精确求解，引擎长程
交付率/平均保真度与之吻合（test/markov.test.ts：率差 < max(1e-3, 3%)，
F 差 < 1e-3，5 种子 × 6×10⁵ 轮）。49 态年龄链（T₂=80, 截止=5）同过。

## 5. 铺贴（tiling）与交换级联

路径铺贴 = 同主请求的段对路径的**区间精确覆盖**，DP 求解。我们最初的贪心
（按起点排序首适配）在 6 跳链上死锁：短段 (l0+l1) 若 id 小就占位，唯一的
长覆盖 (l0..l4) 被跳过，位置 4 出现空洞 → 永远无铺贴 → 槽满冻结（实测
attempts=65 后全网静止）。DP 修复后 6/8 跳正常交付。

级联合并：铺贴的不相邻节点合并互相独立、同轮并行发出；相邻关节（引用已被
消耗的对）跨轮重铺贴完成。引擎交换为朝向无关合并（任意公共端点），合并后
links 按"endA 侧在前"重排（锚点记账依赖该不变量）。

## 6. 阶梯经济学（ERS 纯化配对的三条实测定律）

BBPSSW 递归的成功配对是**等保真度**的（2^k 阶梯）。调度器看到的是任意
fidELITY 池，三条定律全部由实测失败逼出：

1. **混纯不动点**：固定与新鲜对（F₀=0.85）混纯有不动点 ≈0.9093 < 阶梯目
   标 0.95——迭代混纯永远到不了。必须等保真度配对。
2. **冠军 grazing**：冠军对（0.9494）与平台跑步者（0.9093）混出 +5e-5 的
   "改进"，吃掉构建 0.93 级跑步者的原料 → 系统饱和于 0.9497 < 0.95。
   对策：MIN_GAIN=1e-3 的最低改进门槛 + 自底向上（改进配对里 fHi 最小的
   先融合）。
3. **槽位下限**：冠军 + 2×工作槽是最小配置；slots=3 时 2⁴ 阶梯结构性不可
   行（exp4-A：slots≤3 交付为零，slots≥4 正常）。这是**硬件需求**：同档
   配对需要冠军驻留的同时梯子还有两份工作原料。

压力释放：无改进配对且槽满时丢弃最低的陈旧档（高于新鲜档位的最低对），
让新鲜对能双积累重建梯子。低于 fMin 的完整对 ERS 一律 hold（严格 QoS），
陈旧度由网络截止参数约束。

## 7. 复杂度备注

- 小图（|V|,|E| ≤ 数十）上的 k 简单路枚举精确（DFS + 剪枝）；ET 度量
  Σ 1/p_e 沿用 Q-CAST 传统。
- 网络级**离线最优**尝试槽分配是整数多商品流型问题：Even-Itai-Shamir
  (1976) 证明 2 商品整流已 NP-完全——在线启发式（亏额优先）的定位是近似，
  我们不声称最优性。
- 2 链路链的在线最优可由 DTMC 平稳分析给出结构刻画（Vardoyan 等的开关
  排队论传统）；本仓库的 DTMC 裁判属于同一方法论。

## 8. 实测病理与开放问题（诚实清单）

- **asap 冻结死锁**（exp2-C）：急切合并 + 无释放机制 → 陈旧重叠段占满
  锚点 → attempts 永久停止。低交换成功率通过销毁旧段"被动清道夫"式地
  避免死锁——失败率作为隐式释放机制的悖论值得单独研究。
- **3 槽饱和墙**（exp4-A / §6）：混合阶梯的 0.9497 饱和是动力学不动点，
  不是采样噪声；其严格刻画（不动点 vs 槽位数的一般公式）留作开放问题。
- ERS 在良性区间的吞吐低于 asap（滞后合并的续灌周期更长）；其净增益在
  QoS/公平/纯化维度。区间依赖如实报告，不做单点宣传。

## 9. 与文献的诚实对照

- Pant et al. (2019)：多路径并发建立的思想我们以 k 路径 + 就绪度滞回实现；
  未复现其速率界。
- Shi & Qian (2020, Q-CAST)：ET 度量与恢复思想；未复现其协议逐点对比。
- swap-asap vs swap-late 的优劣是区间依赖的（我们 exp3-A/B 如实显示 asap
  在良性/中等区间吞吐最高）；ERS 的净增益在严格 QoS 区间（exp3-C）与公平
  性维度（亏额仲裁把并发需求逐种子精确均分）。
