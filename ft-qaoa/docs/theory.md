## 1. 深度单调性定理

### 1.1 陈述

设代价算子 `C = Σ_j h_j Z_j + Σ_{(j,k)} w_jk Z_j Z_k`，混合算子 `B = Σ_j X_j`，
初态 `|+⟩^n`。定义深度 p 的 QAOA 目标函数

```
F_p(γ, β) = ⟨+^n| Π_{t=1..p} [e^{iβ_t B} e^{iγ_t C}] C Π_{t=1..p} [e^{-iβ_t B} e^{-iγ_t C}] |+^n⟩
```

与最优值 `M_p = sup_{γ,β} F_p(γ, β)`。则：

**定理 1（深度单调性）。** `M_{p+1} ≥ M_p` 对一切 p ≥ 0 成立。

### 1.2 证明草案

考虑嵌入映射 `ι: (γ, β) ↦ (γ ⊕ 0, β ⊕ 0)`，即在深度 p+1 的参数末尾附加一层零角。
由于 `e^{-i·0·C} = e^{-i·0·B} = 𝟙`（恒等），两个酉作用在态上逐层抵消：

```
|ψ_{p+1}(ι(γ,β))⟩ = e^{-i·0·B} e^{-i·0·C} |ψ_p(γ,β)⟩ = |ψ_p(γ,β)⟩
```

故 `F_{p+1}(ι(γ,β)) = F_p(γ,β)`。对左边取上确界：

```
M_{p+1} = sup_{γ',β'} F_{p+1}(γ',β') ≥ sup_{γ,β} F_{p+1}(ι(γ,β)) = sup_{γ,β} F_p(γ,β) = M_p  ∎
```

**注意定理保证的是最优值的单调性**；任何具体优化器找到的是 `M_p` 的下界。
再由变分原理 `M_p ≤ max_s E(s) = C_opt`，`{M_p}` 单调有界必收敛——这是
"优化质量随深度单调"的严格含义。

### 1.3 可证伪验证协议（引擎级）

定理的每一环都由代码验证，任何实现缺陷都会被测试抓出：

1. **嵌入恒等式**（`verifyEmbedding`）：在 p ∈ {1, 7, 63, 127} 上取种子化随机角度，
   用真实引擎计算 `|F_p(θ) − F_{p+1}(θ⊕0)|`。实测全部 **0.00e+0**（机器精度内为零）。
2. **最优值单调**（exp1 Part B）：p=1..6 全量坐标下降 + 零层热启动（把 p 的优化结果
   零填充为 p+1 起点，正是定理的构造），实测最优值序列非降。
3. **实测序列单调**（exp1 Part C）：r_p 序列（ramp+INTERP 找到的值 / 精确最优）
   在 7 个种子实例上 p: 8→128 全部非降（容差 2e-3 吸收优化器噪声，违规如实报告）。

### 1.4 与绝热极限的联系

线性斜坡 `γ_t = (T/p)·(t/p), β_t = (T/p)·(1−t/p)` 是绝热调度
`H(s) = (1−s)B + sC` 的一阶 Trotter 化。p→∞ 时收敛于时长 T 的绝热演化；
gapped 实例上 T 足够大时 r_p → 1。实测 n=10 实例 r_128 = 0.9999、
n=14 实例 r_128 = 0.991，与该图像一致。**NISQ 与容错 regimes 的分水岭
正在于此**：p>100 层的非对角深度电路只能在逻辑比特上跑（路线主张），
本原型在无噪逻辑层给出了它值得跑的证据。

## 2. 容错资源模型（全部显式假设）

### 2.1 码目录（带出处）

| 码 | [[n,k,d]] | 辅助比特 | 检查数/轮 | 伪阈值（估计输入） | 出处 |
|---|---|---|---|---|---|
| rotated surface | [[d², 1, d]] | d²−1 | d²−1 | 0.6% | Fowler et al., PRA 86, 032324 (2012) |
| gross (BB) | [[144, 12, 12]] | 144 | 144 | 0.7%（0.6–0.8%） | Bravyi et al., Nature 627, 778 (2024) |

### 2.2 逻辑错误（启发式幂律）

```
ε_L/轮 = A · (p_phys / p_th)^{⌊d/2⌋+1},   A = 0.1（显式假设）
```

标准阈值以下幂律抑制形状；A 与指数是估计输入而非精度声称。
每逻辑操作消耗 `factor × d` 轮综合征（格点手术/注入延迟量级，factor=1）。

### 2.3 旋转合成（Clifford+T）

每个任意角旋转 `R_z(θ)` 的 T 计数 `= ⌈c·log₂(1/ε_syn)⌉ + c₀`，默认 c=3, c₀=4,
ε_syn=1e-6（Kliuchnikov-Maslov-Mosca 2013 缩放量级，系数为输入）。
每 QAOA 层的非 Clifford 内容 = `(m + 2n)` 个任意角旋转
（m 个耦合 RZZ + n 个场 RZ + n 个混合器 RX）。

### 2.4 T 工厂（显式假设，实验 2 三档扫参）

| 档 | ns/T | 比特/链 | ε_T |
|---|---|---|---|
| optimistic | 100 | 5,000 | 1e-12 |
| moderate | 10,000 | 5,000 | 1e-12 |
| conservative | 60,000 | 12,000 | 1e-12 |

两级蒸馏量级（Gidney-Ekerå 2019 class）。**单级 1e-8 的 ε_T 对深电路直接压死
一切预算**（L=80/p=128 蒸馏地板 0.032 > 0.01）——这本身是估算器给出的
路线结论：深 QAOA 强制要求多级蒸馏。

### 2.5 组合与判定

```
ε_total = ops · ε_L/轮 · rounds/op  +  T_gates · ε_T
wall_time = ops · rounds/op · τ        （串行逻辑执行，保守）
ops = p · (m + 2n)
```

meetsBudget ⟺ ε_total ≤ 目标（默认 1e-2）。所有常数集中于 `FtAssumptions`，
无隐藏常量。关键诚实发现：gross 码固定 d=12 在 p_phys=1e-3 下对 p≥100 深电路
**超预算**（L=80/p=128: ε=0.075），需 p_phys ≤ 3e-4 或更大距离；
surface 的可调 d 在 1e-3 下承载深电路（d=17-19）。

## 3. 实时解码调度模型

- **到达流**：每码块每 τ=1µs 产生一轮综合征（gross：144 比特/轮/块；
  L=80 → 7 块 → 1008 Mb/s 持续数据率——这本身即调度约束）。
- **解码单元**：每窗口服务时间 `= W/μ + λ`（μ=吞吐, λ=固定延迟），
  服务守恒 FIFO 机队，种子化 ±20% 抖动，窗口 W=8 轮。
- **利用率定律**：`ρ = (W/μ + λ) / (W·τ·k)`，k=每块单元数。
  ρ ≤ 0.95 判 realtime；ρ > 1 积压线性增长（离散事件仿真验证）。

实测结论（exp3）：CPU BP+OSD（1ms/轮）ρ=1125，差三个数量级；
FPGA（100µs/轮）需 ~512 单元机队才 ρ=0.856 过线；µs 级 ASIC 16 单元 ρ=0.313
舒适通过。**实时 qLDPC 解码是路线真瓶颈**——与社区共识一致，这里给出的是
机队规模的定量标度方法。

## 4. 诚实边界（重申）

1. 本原型**不含噪声**：逻辑层无噪模拟正是容错执行后的正确抽象层级；
   物理层噪声仅通过资源估算的 ε 模型进入。
2. 资源估算常数为**文献锚定的假设**，非硬件规格；改动任何假设只需改
   `FtAssumptions` 输入，表格随之重建。
3. 单调性定理**严格成立的部分**是最优值 M_p 的非降（证明 §1.2 +
   恒等式机器验证）；实验序列的单调是优化器质量下的实证，容差内违规会被
   如实写出。
4. gross 码参数（144/12/12、288 总比特、weight-6 稳定子、0.6–0.8% 伪阈值）
   引自 Nature 2024 论文与其公开材料；阈值是估计输入。
