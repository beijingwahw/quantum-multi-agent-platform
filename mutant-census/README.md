# mutant-census — 突变体名册

> 工作区的质量层，被执行为本体：埋藏记录全部缺陷类编译为九个突变算子，
> 在共享内核家系与其标准组合上回放，被十条全输入性质电池逐一击杀。零幸存。
> 内核家系的字节同源与 26 仓工程卫生在每次 `npm test` 时**活普查**——
> 未注册的漂移直接失败构建。而回路一直闭到底：**注册表在册的每一枚错误
> 都被活导入、逐条入册到当下杀死它的守卫上（E 板）——没有执法锚点的
> 错误从此埋不进去。**

- 上诉庭：`npm run repro`（渲染 `out/reports/the-mutant-census.md`，非法名册/非法入册拒绝打印）
- 门禁：`npm test`（击杀普查 9/9 + 性质电池 10/10 + 走私审判 + K/W/E 活普查 + 入口守卫）
- 法律 Q1–Q6：出处（每个突变体必引埋藏批次）、击杀诚实（声明与活普查必须一致）、
  性质非例子（≥60 种子化输入，最坏偏差入册）、灵敏度（每条性质必须能被击倒）、
  家系同源（注册表与现实精确互指）、词表封闭/锚点在盘。
- 法律 E1–E6：**双向精确覆盖**（活注册表每错恰一行、每行必有错——无锚点之错埋不进）、
  突变系带（MUTANT-KILLED 行必须坐在申报了该缺陷类的突变体上）、
  活锚点（GATE 行的"文件 :: needle"必须在盘）、可见边界（BOOKED 行必带理由且
  全数印上报告）、双注册表不得漂移（声明数 = 载荷数）、词表封闭/键唯一/不得改类别。

## 这是什么

- **M 板（击杀名册）**：9 个突变体，每个重演一个真实历史缺陷类（共轭侧符号三犯、
  ρ 转置、8×8 静默膨胀、忘 ⊗I、联合概率元归一化、Kraus 方向反、极限对象写错、
  MC 事件错配、统计分母错），6 EXACT + 1 CRASH + 2 DATA 击杀，margin 入册。
  每个突变体申报自己的缺陷类（`classes`）——E 板的系带就系在这里。
- **P 板（性质电池）**：10 条性质，对全体种子化输入成立——形状守卫、态资格
  （Hermitian/迹 1/PSD/双路内积）、代数恒等式、CPTP 保迹、测量与条件化、
  吸收单调、渐近恒等、同事件统计、后选择分母、设置面 no-signaling（含 CNOT 负对照）。
- **K 板（家系活普查）**：cmat/states/channels/rng/measures 五件套在 10 仓字节级
  同源；quantum-mech/qverify 的 states.ts 等 11 处分歧**注册在案**（登记，不裁决）；
  未注册漂移与陈旧注册都是违规——注册表必须与现实精确互指。
- **W 板（卫生活普查）**：26/26 仓 test/typecheck/repro + TS strict 全过；
  批 21 立法前的守卫债已全额清偿（批 33，42 入口三形制补装），注册表清空、
  法律绝对化——零未守卫入口，无豁免通道。
- **E 板（入册活普查）**：埋藏记录由 `src/kernel/bridge.ts` **每次运行活导入**
  （不拷贝——拷贝会漂移，批 23 类），在册错误逐条入册三档：
  **MUTANT-KILLED**（错误所属缺陷类被活突变体重演并击杀——类别级系带）、
  **GATE-ENFORCED**（复发即红一个真实构建门禁；锚点"文件 :: needle"活校验）、
  **BOOKED-UNENFORCEABLE**（机器守不住的线，必带理由，全数印在报告上——
  可见性替代执法）。新批落地时未同步入册 → E1 点名，构建失败。
  决策表（类别默认 + 逐键覆写 + BOOKED 理由）在 `scripts/gen-enrollment.ts`
  作为可审数据维护；权威是 E1–E6 活普查，不是生成器的出处。
- **A 板（锚点见证注册表）**：E3 只证锚点在盘，不证锚点会开火——本板把每个
  GATE 锚点升格为**带证据的注册对象**（`src/kernel/anchors.ts`）：
  **FIRING-INJECT**（注入式定罪演示＝具名真实测试：伪造弹药直接打进兄弟仓的
  真实 checker——checkBurial/checkLedger——被按名定罪）、**FIRING-LIVE**
  （本席现场开火：E1/E2/Q2/Q4/W-C/相位敏感/未守卫探测器每次普查实弹）、
  **RESOLVED**（脚本门禁的实现工件在盘可解析——测试树、typecheck 工程、
  lint 配置、repro 目标、格式化器、总门禁作业构造）。法律 **A1–A3**：
  注册表对称（未注册锚点不得持错、陈旧注册本身违规——K 板对称律的守卫版）、
  演示在盘、见证实弹/工件实解。见证 W-G。

## 诚实的边界

- 突变集是**历史动机**的，非穷尽——等价突变是领域公开问题（JIA11），此处不假装解决。
- E 板的 MUTANT-KILLED 系带是**类别级**：一个突变体守它申报的整个注册类别
  （注册表自身的 B0 分类），不逐错造突变体——逐错回归是民间纪律（"每个 bug 配一条
  测试"），本仓主张的是**机器审计的错误注册表被质量门禁活导入、错误无执法锚点不得
  入册**这条闭环，仅此而已。
- 家系 `mAdd` 不查形状是**记录在案的设计边界**（批 31："维度账永远是写码人的"）——
  MU3 在组合层被维度契约击杀，而非改造会破坏十仓字节同源的加法器。
- 统计击杀是 DATA 级（5σ 判定），精确击杀是精确的。
- W 板未守卫探测是字符串层启发式，漏报如实呈现不执法；K 板的哈希普查才是精确面。
- 层级判定是**记录为数据的判断**：上诉 = 改入册表，而 E1–E6 把这次修改钉在
  注册表、磁盘与算术上。BOOKED 是诚实边界——每行带理由印在报告上。
- "世界前沿"的定价：突变测试（DEM78/JIA11）与性质测试（CLA00）是领域地基，已引用；
  本仓主张的贡献是**机器审计的错误史 → 算子集 → 物理不变量神谕 → 构建门禁 →
  全量入册闭环**这条可执行耦合，仅此而已。
- 本仓是工作区元门禁（同 depreciation-ledger 的 appeal 形制）：K/W/E 板依赖兄弟仓在盘。
