# mutant-census — 突变体名册

> 工作区的质量层，被执行为本体：埋藏记录全部缺陷类编译为九个突变算子，
> 在共享内核家系与其标准组合上回放，被十条全输入性质电池逐一击杀。零幸存。
> 内核家系的字节同源与 28 仓工程卫生在每次 `npm test` 时**活普查**——
> 未注册的漂移直接失败构建。而回路一直闭到底：**注册表在册的每一枚错误
> 都被活导入、逐条入册到当下杀死它的守卫上（E 板）——没有执法锚点的
> 错误从此埋不进去。**

- 上诉庭：`npm run repro`（渲染 `out/reports/the-mutant-census.md`，非法名册/非法入册/非法自述报告拒绝打印）
- 门禁：`npm test`（击杀普查 9/9 + 性质电池 10/10 + 走私审判 + K/W/E 活普查 + 入口守卫
  + S1/S2 自述报告门禁——板序法定、散文对账，盘上工件活校验）
- 法律 Q1–Q6：出处（每个突变体必引埋藏批次）、击杀诚实（声明与活普查必须一致）、
  性质非例子（≥60 种子化输入，最坏偏差入册）、灵敏度（每条性质必须能被击倒）、
  家系同源（注册表与现实精确互指）、词表封闭/锚点在盘。
- 法律 E1–E6：**双向精确覆盖**（活注册表每错恰一行、每行必有错——无锚点之错埋不进）、
  突变系带（MUTANT-KILLED 行必须坐在申报了该缺陷类的突变体上）、
  活锚点（GATE 行的"文件 :: needle"必须在盘）、可见边界（BOOKED 行必带理由且
  全数印上报告）、双注册表不得漂移（声明数 = 载荷数）、词表封闭/键唯一/不得改类别。

## 这是什么

- **M 板（击杀名册）**：9 个突变体，每个重演一个真实历史缺陷类（共轭侧符号三犯、
  ρ 转置、8×8 静默膨胀、忘 ⊗I、联合概率元归一化、Kraus 方向反、极限对象写错、
  MC 事件错配、统计分母错），6 EXACT + 1 CRASH + 2 DATA 击杀，margin 入册。
  每个突变体申报自己的缺陷类（`classes`）——E 板的系带就系在这里。
- **P 板（性质电池）**：10 条性质，对全体种子化输入成立——形状守卫、态资格
  （Hermitian/迹 1/PSD/双路内积）、代数恒等式、CPTP 保迹、测量与条件化、
  吸收单调、渐近恒等、同事件统计、后选择分母、设置面 no-signaling（含 CNOT 负对照）。
- **K 板（家系活普查）**：cmat/states/channels/rng/measures 五件套在 10 仓字节级
  同源；quantum-mech/qverify 的 states.ts 等 11 处分歧**注册在案**（登记，不裁决）；
  未注册漂移与陈旧注册都是违规——注册表必须与现实精确互指。
- **W 板（卫生活普查）**：28/28 仓 test/typecheck/repro + TS strict 全过；
  批 21 立法前的守卫债已全额清偿（批 33，42 入口三形制补装），注册表清空、
  法律绝对化——零未守卫入口，无豁免通道。
- **E 板（入册活普查）**：埋藏记录由 `src/kernel/bridge.ts` **每次运行活导入**
  （不拷贝——拷贝会漂移，批 23 类），在册错误逐条入册三档：
  **MUTANT-KILLED**（错误所属缺陷类被活突变体重演并击杀——类别级系带）、
  **GATE-ENFORCED**（复发即红一个真实构建门禁；锚点"文件 :: needle"活校验）、
  **BOOKED-UNENFORCEABLE**（机器守不住的线，必带理由，全数印在报告上——
  可见性替代执法）。新批落地时未同步入册 → E1 点名，构建失败。
  决策表（类别默认 + 逐键覆写 + BOOKED 理由）在 `scripts/gen-enrollment.ts`
  作为可审数据维护；权威是 E1–E6 活普查，不是生成器的出处。
- **A 板（锚点见证注册表）**：E3 只证锚点在盘，不证锚点会开火——本板把每个
  GATE 锚点升格为**带证据的注册对象**（`src/kernel/anchors.ts`）：
  **FIRING-INJECT**（注入式定罪演示＝具名真实测试：伪造弹药直接打进兄弟仓的
  真实 checker——checkBurial/checkLedger——被按名定罪）、**FIRING-LIVE**
  （本席现场开火：E1/E2/Q2/Q4/W-C/相位敏感/未守卫探测器每次普查实弹）、
  **RESOLVED**（脚本门禁的实现工件在盘可解析——测试树、typecheck 工程、
  lint 配置、repro 目标、格式化器、总门禁作业构造）。法律 **A1–A4**：
  注册表对称（未注册锚点不得持错、陈旧注册本身违规——K 板对称律的守卫版）、
  演示在盘、见证实弹/工件实解、**工件开火（A4，v0.11.0 深检二层）**——
  总门禁已经开过火，普查从最近记录的工件里**收割开火记录**：RESOLVED 的
  test/typecheck 锚所在仓在最近一次总门禁运行里红格 → 违规（RESOLVED 的
  证据从"机器在盘"深化为"机器开火且绿"；lint/repro 锚在交付时开火、
  不在总门禁射程——A4 对其不主张）。见证 W-G。
- **J 板（逐错等价普查，v0.8.0；v0.13.0 四类全穷尽）**：E 板系带是类别级——本板把"逐错构造突变体"
  这个 JIA11 公开问题**在真实错误史上量完**（`src/kernel/equiv.ts`）：
  **四类全穷尽＝全部 117 行 MUTANT-KILLED 逐错普查**（conjugation 19/19、
  wrong-object 44/44、dimension-slot 29/29、statistics 25/25）。
  每错按其错误文本做家族层忠实再造，跑全电池，判据词表封闭：
  **COLLAPSES 九枚**——**九个原型全部有亲源错标本**（b29#0≡MU1、b20#0≡MU2、
  b31#4≡MU3、b24#0≡MU4〔经崩溃面位精确——电池崩溃容量化后 print 可比〕、
  b21#0≡MU5、b31#0≡MU6、b31#3≡MU7、b31#5≡MU8、b19#3≡MU9）：
  类别系带就是逐错构造的不动点，九比九；
  **ERROR-LEVEL 十二枚**——独立构造被活击杀（含 dimension-slot 的张量写成乘积
  b13#2〔P2〕与 1×1 阵缩放 b31#1〔P5 崩溃面，与 MU3 的 P2 面不同故不坍缩〕）；
  **EQUIVALENT 两枚、两个物种**——b30#0（**表示盲**：全局相位密度层不可见，
  逐元素证明）与 b5#2（**输入覆盖盲**：无守护 0/0 活在电池输入分布永不触及的
  退化分支上——P(零接受)≤0.7^60 概率界证明；在一切被触及的输入上构造是
  正确估计量）——**JIA11 现象不是一堵墙，至少是两堵**；
  **UNBUILDABLE 九十四枚**——缺陷母体（优化器/本征求解器/模拟器/协议/验证器/
  指标约定/标定选择/性质内部构造）不是家族成员，逐行带理由。
  可判定的交换写进法律：
  **程序等价不可判定，电池不可分辨性是机器逐位可判的关系**。法律 **J1–J3**：
  覆盖双向穷尽（四类）、判决＝活普查、EQUIVALENT/UNBUILDABLE 必带理由。见证 W-I。
- **R 板（修复审计，v0.10.0；v0.11.0 深检扩法）**：BOOKED 理由是全称命题（"没有机器守得住这条线"）——
  全称命题不可证明、只能被一台台见证机器**否证**。本板把 v0.9.0 的单批处置审计
  升为**全账本常设法**（`src/kernel/repair.ts`）：全账本 BOOKED 逐行以可判据
  （**复发是否死于一张排程门禁**）审计——**UPGRADED**（理由已被机器推翻：
  要么 sighting 本身被门禁当场定罪〔b47#1 的装载器、b56#7 的精确零容差、
  b37#1 的模块解析〕，要么门禁树内复发即红〔TS2305/TS2304，b46#2/b54#2 先例〕，
  行改坐活锚点，判据里**逐字引用否证锚**〔R2〕——十行，含 b37#7 的仓表
  单源化同刻修复，与 b67#6 一访后的 R1 同刻升档〔E7 建成之日其否证靶兑现〕）、
  **SHARPENED**（理由成立但粗：按 b54#1 双面先例改写，
  点名哪一面在册、哪一面已被门禁持有——十五行）、**HELD**（理由照写成立，
  basis 写明不可执法的面——瞬态 shell 行为、上机前草稿、环境、外部真值、
  散文意图）。法律 **R1–R4**：**R1 出生即审计**（新 BOOKED 行
  不带审计判词 → 构建红；日后的档位翻转不同刻改审计行 → 构建红）、
  **R2 否证锚逐字引用**、R3 词表封闭/键唯一/basis 非空、
  **R4 开火证据（v0.11.0 深检）**——每个 UPGRADED 行在被引门禁自己的树里
  携带**针级见证**（文件在盘＋恰好行使该缺陷类的断言/include/导入原文），
  每次运行活校验。见证 W-Y。
  判词层是作者判断记录为数据——机器持有覆盖、词表与引用，不持有判词的智慧。
- **E7（自述计数法，v0.11.0）**：普查自己的散文面也是数据的副本——
  package.json 描述里申报的档位计数（"N on live mutants / N on build gates /
  N booked unenforceable"）必须等于活入册算术；渲染器拒绝打印自述漂移的普查。
  b67#6（十一访漂移）与 b68#0（同日再犯——批 67 落地 +3 门禁/+4 在册、
  描述没回头同步）由本法持有。
- **S1/S2（自述报告法，v0.22.0——HELD 行定价的两个否证靶兑现）**：
  渲染出来的报告本身也是数据的副本。**S1 板序检查器**：段序是法
  （M→P→对照→K→W→E→A→G→J→R→T→见证→边界→结语，十四段封闭词表、
  各段恰一次；段内 M 板行按 id 升序、A 板按证据档位排序）——置换的段、
  乱序的行、未立法的新段都被点名拒绝（b59#6 类）。**S2 散文对账门禁**：
  报告散文里的每一个数字声明都等于注册表/内核的活算术（五十五项定点声明＋
  家族份额、类目表、全成员名单的动态声明）——渲染器自检不过拒绝打印，
  测试套件每次运行对**盘上工件**活重推导，被篡改或陈旧的
  `out/reports/the-mutant-census.md` 直接红构建并点名漂移字段
  （b36#16/b57#5 类；本法首跑即定罪三处已随船漂移的散文：十全成员对活七、
  quantum-mech 四/五对活三/五、R 板九/十五对活十一/三十三）。W-S 见证行入册。
  两个否证靶由此从"已定价"变为"已执法"——持的是**普查自述报告**这一面；
  兄弟仓的散文与板面仍在各自 HELD 行上（b12#7/b19#5/b21#3/b36#16/b51#5/
  b57#5/b59#6/b74#8/b76#7 的 basis 已同刻改写）。

## 诚实的边界

- 突变集是**历史动机**的，非穷尽——等价突变是领域公开问题（JIA11），此处不假装解决；
  conjugation 类自 v0.8.0 起带**逐错等价普查**（J 板）：一枚**可证明的**等价标本
  已入册（b30#0：全局相位在密度层不可见——缺陷真实存在于 ket 层，家族因表示层而盲）。
- E 板的 MUTANT-KILLED 系带是**类别级**；conjugation 类的逐错问题已被 J 板**穷尽丈量**
  （19/19：2 坍缩、7 逐错击杀、1 可证等价、9 不可构造），其余三类（wrong-object 44、
  dimension-slot 29、statistics 25）保持类别级、定价为下一步。逐错回归是民间纪律
  （"每个 bug 配一条测试"），本仓主张的是**机器审计的错误注册表被质量门禁活导入、
  错误无执法锚点不得入册**这条闭环——加上"逐错系带在可判定处被逐错丈量"，仅此而已。
- 家系 `mAdd` 不查形状是**记录在案的设计边界**（批 31："维度账永远是写码人的"）——
  MU3 在组合层被维度契约击杀，而非改造会破坏十仓字节同源的加法器。
- 统计击杀是 DATA 级（5σ 判定），精确击杀是精确的。
- W 板未守卫探测是字符串层启发式，漏报如实呈现不执法；K 板的哈希普查才是精确面。
- 层级判定是**记录为数据的判断**：上诉 = 改入册表，而 E1–E6 把这次修改钉在
  注册表、磁盘与算术上。BOOKED 是诚实边界——每行带理由印在报告上；自 v0.10.0
  起每条理由本身也是被审计的数据（R 板）——被推翻的升档于被引用的活锚点，
  幸存的写明自己的不可执法面与**否证靶**（散文对账门禁与板序检查器两个靶
  已于 v0.22.0 兑现为 S2/S1——但只持有普查自述报告那一面；兄弟仓的散文/板面
  仍在各自的 HELD 行上定价）。
- "世界前沿"的定价：突变测试（DEM78/JIA11）与性质测试（CLA00）是领域地基，已引用；
  本仓主张的贡献是**机器审计的错误史 → 算子集 → 物理不变量神谕 → 构建门禁 →
  全量入册闭环**这条可执行耦合，仅此而已。
- 本仓是工作区元门禁（同 depreciation-ledger 的 appeal 形制）：K/W/E 板依赖兄弟仓在盘。
