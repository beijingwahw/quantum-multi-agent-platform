# hardware-spec.md — 可编程非 stoquastic 退火机目标规格（v0）

> 定位：路线目标规格（roadmap #5）。实验室演示已存在（2 比特 ZX 型耦合，
> Ozfidan et al., PRA 13, 034037 (2020)）；**生产级多比特可编程非 stoq 驱动
> 不存在**——本文档 + `src/hardware/profile.ts`（机器可读剖面）定义它应
> 满足什么。所有常数是锚定本仓库 exp1-exp5 模拟包络的显式假设。

## 1. 耦合器菜单（单位：Γ=1 归一）

| 类型 | 范围 | 校准容差 | 角色 |
|---|---|---|---|
| ZZ | [−2, 2] | 3% | 问题项（标准退火耦合器） |
| XX | [−2, 2] | 4% | 反铁磁 XX 催化剂；κ>0 为非 stoquastic（规范不可约，见 §4） |
| ZX | [−1, 1] | 5% | Ozfidan 2020 已演示的类型；对角规范逐项可去（de-signing 判定器管辖） |

其余：64 逻辑比特（v0），连接度 4，Γ ∈ [0.2, 2.0]，两参数路径时序分辨率 0.05 µs。

## 2. 驱动器基态制备（exp2 发现的硬需求）

κ > 2Γ 后驱动器基态不再是 |+⟩^n（含符号结构甚至反关联）。绝热协议要求
初态 = H(0) 基态 ⟹ **硬件必须能制备自身驱动的含符号基态**——这是非 stoq
路线被低估的工程前提，写进剖面校验锚点 `driver-ground-preparation`。

## 3. 与模拟包络的对齐

- κ 范围覆盖 exp1（壁垒扫描 κ ≤ 1.0）、exp4（Nishimori-Takada 路径 s(1−λ)
  项）、exp5（DMRG 扩规模 κ = 1.0）；
- 连接度 4 覆盖链/环/稀疏随机图族；全连通 p-spin 家族超出 v0（标注：需
  更高连接度或嵌入）。

## 4. 符号壁垒的硬件意义（与 de-signing 判定器联动）

- **均匀横场 + 任一 κ>0 的 XX 边在对角规范下不可去**（designing.ts 闭式
  定理 + 稠密矩阵裁判）——经典世界线采样器的符号代价无法被基选择消除；
- 机器在该配置下的采样分布携带计算基符号结构（exp5：κ=1.0 链负分量
  46-52% @ n=64）——这是相对经典模拟的专属壁垒候选；
- ZX 耦合逐项可去，其价值在光谱与制备（Ozfidan 演示），不在壁垒。

## 5. 片上验证协议（校准锚点，机器形态见 CALIBRATION_ANCHORS）

1. `stoq-baseline-positivity`：κ=0 设置下基态采样对照 PF 非负基线（exp1
   对照：P = 1.000000）；
2. `pair-spectroscopy-kc`：双比特对谱在 κ_c = 2Γ 相变——片上可复现的解析
   锚点（本仓库测试机器验证）；
3. `xx-irreducibility`：κ>0 XX 的规范不可约性（判定器证书）；
4. `driver-ground-preparation`：κ>2Γ 驱动器基态制备保真度。

## 6. 诚实边界

- 剖面常数是假设不是规格书；量级锚定 Ozfidan 2020 与本仓库模拟；
- 元素级 de-signing（含元素求和，如强 X+ZX 抵消）是开放问题，判定器只做
  逐项判定；
- 量子优势声称不在本文档范围——壁垒（exp1/3/5）与收益（exp4 负结果如实）
  分开陈述。
